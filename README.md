# Spotify Audio Analysis 🎵

This project explores Spotify track data using Exploratory Data Analysis (EDA) techniques to understand patterns in music features such as energy, danceability, acousticness, and popularity.

## 📊 Objectives

- Understand dataset structure
- Identify missing values and duplicates
- Explore distributions of audio features
- Analyze relationships between variables
- Visualize insights using Python

## 🛠 Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Key Insights

- Audio features show varying distributions across songs
- Some features like energy and danceability show weak/moderate relationships
- Genre distribution is uneven across the dataset

## 📁 Files

- `spotify_eda.ipynb` → Main analysis notebook
- `dataset.csv` → Spotify tracks dataset
